# SelfDiff · 见己 v0.1.1

修复模型设置页的加载竞态：旧配置尚未返回时，输入与保存暂时禁用，避免异步响应覆盖刚输入的接口地址和模型名。新增慢响应浏览器回归测试。

包含 v0.1.0 的跨来源会话导入、六维个人档案、原文证据、本人修订、判断对照、时期比较、快照与导出功能。默认本机存储，用户启动分析后才向其配置的模型发送所选资料。

验证：62 项后端测试、7 项 Chromium 浏览器测试；Windows/Linux × Python 3.10/3.12；前端构建与全新环境安装包启动。示例完全合成；本机假 HTTP 模型测试不代表真实供应商或个人分析质量验收。

需要 Python 3.10+；wheel 已内置前端，无需 Node.js。

```sh
python -m pip install https://github.com/wind127/selfdiff/releases/download/v0.1.1/selfdiff-0.1.1-py3-none-any.whl
python -m selfdiff.cli serve
```

Codex、Claude Code、WorkBuddy 支持已测试的 JSONL 格式族；ChatGPT/Claude 网页使用官方 JSON/ZIP；豆包、DeepSeek、千问办公等通过标准 JSON 或带角色的文本导入。尚未实现所有云端账号的全历史扫描。

附件由 GitHub Actions 从不可变标签构建、安装检查后发布，包含 wheel、源码 sdist 与 SHA256SUMS.txt。保留原有 v0.1.0 标签和附件。
