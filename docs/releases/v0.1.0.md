# SelfDiff v0.1.0

首个本地可运行版本：跨来源会话导入、六维个人档案、精确证据校验、本人修订、自我判断对照、两时期比较、快照、JSON/Markdown 导出和手动确认的分享卡。

发行包含 Python wheel（内置前端）与源码 sdist。普通使用者需要 Python 3.10+，不需要 Node.js。

支持格式族：Codex、Claude Code、WorkBuddy JSONL，ChatGPT/Claude 网页官方 JSON/ZIP；DeepSeek、豆包、千问办公及其他工具使用标准 JSON 或带角色的文本。未实现云端账号全历史抓取。

示例和截图完全合成。模型接口流程通过本机假 HTTP 服务测试；未使用用户的真实会话或凭据验证付费供应商，分析质量需要本人逐项检查证据和情境。

安装：

```sh
python -m pip install https://github.com/wind127/selfdiff/releases/download/v0.1.0/selfdiff-0.1.0-py3-none-any.whl
python -m selfdiff.cli serve
```
