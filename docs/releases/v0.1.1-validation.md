# v0.1.1 validation and implementation decisions

The original independent whole-branch review and seven finding fixes are documented in [v0.1.0 validation](v0.1.0-validation.md). A later hosted CI run exposed a model-settings load race. A deterministic delayed-response browser test reproduced typed values being reset; controls now wait for loaded settings and unmounted requests cannot update the view.

Local patch checks: 62 backend tests (one upstream deprecation warning), 7 Chromium browser tests, TypeScript and production UI build. No real conversations or paid-provider credentials were used. The release workflow builds and installs packages from an immutable verified tag; downloaded public artifacts are checked independently. Hosted checks and publication are recorded by GitHub Actions and the release assets.
