# v0.1.0 validation and implementation decisions

All fixtures, demo conversations and screenshots are synthetic. No personal conversations or paid provider credentials were used.

Local verification: Python 3.10 / Windows, 62 backend tests; Node 22, TypeScript/Vite build and 6 Chromium browser tests. The browser suite covers import, a real local fake-provider HTTP flow, evidence, revisions, comparison, snapshot, exports, deletion, refresh/cancellation, and desktop/mobile layouts. One upstream Starlette/AnyIO deprecation warning remains.

One independent whole-branch review identified six Important findings. Its Markdown archive omission was regraded Important. All seven were addressed in one fix pass with failing regression tests observed before fixes, followed by the complete green suites. There was no second reviewer run.

Release package and hosted CI checks are recorded by the GitHub checks and release assets. Protocol fixtures do not establish real model quality or universal export compatibility.
