# 隐私与资料生命周期

SelfDiff 默认绑定本机 loopback；不设置云端账号、数据库、同步或默认遥测。前端静态资源、系统字体与合成示例均在本机，不加载公共 CDN。

导入只读取本人选中的文件/目录。预览保存在当前本机服务内存中，30 分钟过期，最多保留三份待确认预览。确认后，原文与版本进入指定数据目录的 SQLite。原始外部文件不被修改。

导入、搜索、修订、删除不需要模型网络请求。点击连接测试时只发送无个人资料的短请求；启动分析/判断/比较时，将所选用户发言、引用和候选发现发往配置的模型服务，遵循该供应商的数据处理方式。没有任何账号历史抓取或浏览器凭据提取。

密钥来自服务器环境 `SELFDIFF_API_KEY`。数据库仅保存非秘密的模型地址和名称；不保存密钥。供应商错误不会把请求正文或凭据返回界面。不要将密钥放在地址、模型名称、会话文字或公开报告中。

本地页面使用启动令牌交换 HttpOnly/SameSite 会话；API 检查 Host、Origin 和写操作令牌。服务设计用于本人本机，不应通过反向代理、端口映射或公开监听暴露给其他人。

删除一段会话时删除其全部消息版本和证据，并保守清空当前资料空间的所有派生洞察正文、人工修订、快照和分析缓存，只留下无正文的失效标识。正在运行的旧分析不能重新写回。其余会话仍可重新分析。此前手动下载的 JSON、Markdown、分享卡和系统备份由用户自行管理。

完整导出包含原话与修订，属于私密资料。分享卡另行制作，需主动选取发现、自己填写公开文字并确认；不自动附上原话、路径、会话 ID/链接或日期。应用不自动公开发布。

合成示例与自己的资料空间按 workspace ID 隔离。测试、截图与发行包只使用合成材料，测试入口和假的模型服务不属于运行时功能。

官方完整导出重新导入时，当前分支成员会替换旧分支；旧版本仍保留供历史证据回查，但不参与新的分析。引用旧版本或移出分支的当前档案会失效。快照保留保存时的具体发现、引用、本人修订；删除来源时仍按上述规则清除。

用户驳回过判断后，新模型候选进入“待重新审阅”，须逐项确认才回到当前档案。模型自由生成的总结不直接展示为个人结论；每次任务展示经过引用与范围校验的具体发现。单次最多复核 64 组候选，超出会标记分析不完整，须缩小范围重试。

任务状态保存在本机数据库；页面只记住资料空间 ID 与当前页面以支持刷新恢复。可以在任意页面取消当前空间的后台任务；取消会停止后续请求，已发出的供应商请求仍可能计费。
