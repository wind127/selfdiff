# SelfDiff v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付并公开发布一个可本地运行的个人洞察应用，让用户从跨平台 AI 会话中发现有证据、可修正、能比较变化的个人模式。

**Architecture:** Python 服务负责来源解析、SQLite 存储、证据验证与模型任务；React 界面只调用同源本地 API。领域服务供 CLI 与 API 共同使用；生产 wheel 内含前端静态资源和完全合成的示例。各任务组成一个纵向产品闭环，无需拆出独立部署的服务。

**Tech Stack:** Python 3.10+、FastAPI、Pydantic 2、SQLite 标准库、httpx、pytest；Node.js 22.12+、React、TypeScript、Vite、Playwright。依赖在任务 1/9 中解析并提交精确锁文件；不依赖 CDN。

**Dependency baseline:** 已在 2026-10-18 通过 PyPI/npm 注册表只读核对：`fastapi==0.145.0`、`uvicorn==0.54.0`、`httpx==0.28.1`、`pydantic==2.14.1`、`python-multipart==0.0.32`；开发 `pytest==9.1.1`、`build==1.6.1`、`setuptools==84.0.0`。前端 `react/react-dom 19.3.1`、`vite 8.3.4`、`typescript 7.0.2`、`@vitejs/plugin-react 6.1.2`、`@playwright/test 1.64.1`。这些是实现初始固定版本，尚未安装验证；若依赖解析冲突，仅在保持 Python 3.10/Node 22 约束下调整并记录锁文件。

## Global Constraints

- 名称 SelfDiff / 见己、MIT 许可证、本地运行、中文优先并提供英文 README、不设置账号与云端数据库。
- 采用 Python 3.10+ 本地服务、FastAPI、SQLite，以及 React + TypeScript 前端。
- 开发端使用 Node.js 22；本机 v22.17.1 满足 Vite 当前文档的 22.12+ 下限。
- 服务默认只监听 `127.0.0.1`；默认端口 8765；默认资料目录为用户主目录下 `.selfdiff`。
- 普通用户运行发布包无需安装 Node.js；前端资源、字体与示例不依赖公共 CDN。
- 单文件上传上限 50 MiB；ZIP 解压总上限 200 MiB、文件数上限 200，拒绝路径穿越、符号链接和超限内容。
- 用户选择文件或目录后先预览来源、数量与时间范围，再确认导入；不自行搜遍硬盘或抓取浏览器登录态。
- 演示数据全部从头创作并明确标注；示例使用独立工作区，不能与用户资料混合。
- 反复模式默认需要来自至少两个不同会话的支持；不生成无证据的定量评分。
- 引文必须是对应消息的非空子串；助手生成的总结不能作为用户亲自陈述的证据。
- 密钥在服务器进程环境中使用，前端不接收明文回读；首版不提供明文密钥持久化功能。
- 任务支持取消；重启后未完成任务标记“已中断”，不默默继续发送请求。
- 驳回的结论不进入当前档案，也不能被后续分析静默复活；只有用户主动重新审阅才能恢复。
- 删除源材料后，清空受影响洞察、修订和快照中的关联生成内容；不保留原文或生成的个人结论。
- 不默认开启遥测或自动上传；公开目标 `wind127/selfdiff`，版本 `v0.1.0`，不得覆盖已有仓库。

## Review Focus

1. Windows 中文路径、UTF-8 BOM、无时区或未知时间：能够导入与检索；未知时间不参加趋势。任务 2/3/6 覆盖。
2. 同一会话的重试、增量、分支、压缩回放：不重复计数，旧引用不指向新文字。任务 2/3/4 覆盖。
3. 模型输出包含恶意 Markdown、越界 ID、第三方引文、注入指令：不执行内容，不升级为个人事实。任务 4/5/10 覆盖。
4. 分析与删除/取消同时发生：旧任务不能重新写入已删除材料的结论；重启不发送网络请求。任务 3/5/7 覆盖。
5. 网络失败、超时或部分批次成功：原资料不丢失、覆盖率可见、无演示填充、日志无正文和凭据。任务 5/7/11 覆盖。

## Shared Contracts

- `SourceKind`: `normalized|codex|claude-code|workbuddy|chatgpt|claude-web`；DeepSeek、豆包、千问办公先用 `normalized`，未经真实结构验证不增加原生标签。
- `ConversationInput`: `external_id`, `title`, `source`, `messages`, `branch_id?`；`MessageInput`: `external_id`, `role`, `text`, `occurred_at?`, `content_kind`, `parent_id?`。
- `role`: `user|assistant|system|tool|unknown`；无外部 ID 时用同一输入文件身份与消息位置生成稳定 ID，不用文本单独作会话 ID。外部身份/分支去重仅在来源有明确关系时进行，不靠相似文本猜测。
- `content_kind`: `self_report|question|hypothetical|quoted|tool|assistant|uncertain`；解析器只做确定性标记，个人事实仍需后续验证/用户确认。
- `EvidenceRef`: `message_id`, `version`, `quote`, `relation: support|counter|context`；服务从数据库回填出处，模型无权提供原文位置或路径。
- `InsightDraft`: `pattern_key`, `dimension`, `kind`, `title`, `observation`, `context`, `alternatives[]`, `question`, `evidence[]`；`dimension`: `goals_values|thinking_decisions|learning_collaboration|action_results|interests|change`；`kind`: `recurring_blocker|success_condition|self_judgment|period_change|background`，最后一种仅用于单次明确自述背景。
- `ParseResult`: `conversations: list[ConversationInput]`, `warnings: list[str]`, `unsupported_count: int`；`ImportSummary`: `added_conversations`, `added_messages`, `updated_messages`, `unchanged_messages`, `warnings`。
- `ImportPreview`: `preview_id`, `source`, `input_hash`, `conversation_count`, `message_count`, `known_time_range`, `warnings`；服务端持有解析内容，不将原始路径/文件句柄作为客户端可修改的确认凭据。预览 30 分钟过期，之后要求重新预览。
- `AnalysisRun.status`: `queued|running|succeeded|partial|failed|insufficient|cancelled|interrupted`；保留 `total_batches`, `completed_batches`, `rejected_candidates`, `data_version`。预览估算与实际使用分别记录；模型上下文字符上限/单批消息上限作为可调整服务常量，默认 24,000 字符/40 条。
- `Scope`: `workspace_id`, `source_ids[]?`, `start?`, `end?`；日期按 UTC 保存，UI 显示本地日期；时间区间采用 `[start, end)`。
- 统一错误 `{code, message}`，不携带原文、供应商响应体、路径堆栈或凭据。实际鉴权规则见任务 7。
- API 返回业务 ID 与分页游标；所有读取和修改都校验 workspace，演示与真实资料不能串读。

### Task 7: 本地 API 与 CLI
